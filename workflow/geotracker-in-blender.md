# GeoTracker in Blender

**GeoTracker Analysis**

* Click N (in blender)
* Select GeoTracker (on the lateral panel - for plugin)
* Click on "Create new GeoTracker"
* On "Inputs", click on the "Clip" Folder (in red)
* On the Explorer, go up one time
* Find and open the cinemaEXR\_SHOT001 folder (if the shot is named SHOT001)
* Select All EXR (A)&#x20;
* Click Load Clip
* Set Start Frame to 1
* Click on "Analyse"

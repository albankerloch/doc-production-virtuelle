# Find start / end frames in DVR

**Media**

* Create a new project in DVR
* Import all the shots from the "Footage/Takes" folder in the Projet folder :&#x20;
  * right-click on the "Footage/Takes" folder&#x20;
  * click on Add Folder and Subfolders into Media Pool

<figure><img src="../.gitbook/assets/image.png" alt="" width="375"><figcaption></figcaption></figure>

**Edit**

* See the name from Autoshot in Take Selection
* Drag the shot with "zl\_cam.mp4" at the end in the timeline&#x20;
* Right-click on the timecode next to the Timeline
* Select Source Frame

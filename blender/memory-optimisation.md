# Memory Optimisation

Optimisation tips :&#x20;

* Instanciation (Alt+D)
* Modifier Decimate ou les Proxy for large asset in the background
* Textures
* Mode Blender File in Outliner (Images or Meshes)
* Simplify mode
* Data menu
* Collection Instances

**Simplify mode :**&#x20;

* In Render properties, tick the Menu Simplify
* Set the :&#x20;
  * Texture Limit : 2048
  * Max Subdivision : 2
  * Max Child Particles : 0.2

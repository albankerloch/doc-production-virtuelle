# Polycam for SynthEyes

**Blender**

* Create a new scene
* Save it on the scene folder (Post-Prod/Blender/Structure.blend)
* Delete the starting Cube
* Create a new collection Structure
* Import the .obj downloaded from Polycam
* Move the object to ground level (G + Z)
* Move the object to the origin (G + X and G + Z)
* Set the Origin (Object -> Set Origin ⇒ Origin to 3D cursor)
* Rotate the object to have a correct direction at the origin (R + Z, 180)
* File ⇒ Export ⇒ Waveform (.obj)
* Choose the scene folder (Asset/Polycam)

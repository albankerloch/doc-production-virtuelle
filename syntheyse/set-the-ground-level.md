# Set the ground level

**Setting the ground level**

Before the first solve of the shot, on the Solve or Summary tab

Unset ground trackers :

* select all trackers (Ctrl + A)
* Right lick ⇒ Coordinates ⇒ On the floor
* Right lick ⇒ Coordinates ⇒ On the floor

Set ground trackers :

* Select a maximum of trackers on the floor (right click in a blank area to use lasso select)
* Right lick ⇒ Coordinates ⇒ On the floor

**Adjusting the ground level**

In the 3D tab, select Quad Perspective in Layout

Select Lock in the viewport on the rigth bottom part

Tick Whole

Select the Rotate button

Rotate on the 3 axis (= 3 views)

Select the Deplace button

Deplace the ground on the 3 axis

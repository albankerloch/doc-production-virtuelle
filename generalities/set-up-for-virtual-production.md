# Set Up for Virtual Production

**Charge the batteries**

* For the Sigma FP (alternative : plugged with false battery)
* 2 NP-F for the Video Assist (alternative : plugged with Video Assist Charger)
* 1 NP-F for slider (alternative : plugged with USB C Charger)
* Internal battery of the Ronin RS4 Pro  (alternative : plugged with USB C Charger)
* iPhone for Polycam and RS4 Pro control (alternative : plugged with USB C Charger)
* Microphone RODE



**The Set**

* Add 3D marker is needed to help 3D tracking :
  * with green adhesive tape on a green screen
  * with black adhesive tape on the scene
* Clean the floor



**Camera Setting**

* Disable stabilization (inexistant on Sigma FP, expect with some lense)
* Set the Aperture (1/50)
* Set the Speed (25 fps)
* Apply the setting for Video Assist in System :&#x20;
  * Select HDMI Output to “Recorded Image Output”
  * Select the “Output Format to “RAW”
